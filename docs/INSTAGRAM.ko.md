# 인스타그램 → 노션 자동 정리

인스타 게시물을 노션 **INBOX** 페이지에 공유하면, 1시간 안에 해시태그를 보고 알맞은 탭으로 옮기고 사이트도 업데이트해요.

## 쓰는 법 (게시물마다)

1. 인스타에 게시물을 올려요. 캡션에 아래 해시태그 중 하나를 넣어요.
2. 게시물의 **공유(종이비행기)** → **링크 복사** 또는 **공유 → Notion** 을 눌러요.
3. 노션의 **JUWON's ARCHIVES → INBOX** 페이지에 넣어요.
   - 노션 앱 공유: 공유 → Notion → 위치를 INBOX로 선택 → 저장
   - 링크 복사: INBOX 페이지에 붙여넣기 (북마크/링크 어느 형태든 괜찮아요)
4. 끝. 1시간 안에 알맞은 탭 맨 아래에 새 구역으로 들어가고, INBOX에서는 지워져요.
   급하면 GitHub → Actions → Deploy → **Run workflow**.

## 해시태그 규칙

| 캡션에 넣을 해시태그 | 들어가는 노션 탭 |
|---|---|
| `#3d` | 3D DESIGN |
| `#ai` | AI GENERATED |
| `#graphic` | 2D GRAPHIC |
| `#touchdesigner` | TOUCHDESIGNER |

- 해시태그가 여러 개면 **캡션에서 먼저 나온 것**을 따라가요.
- `#3dart`, `#aiart`처럼 비슷하기만 한 태그는 해당하지 않아요.
- 해시태그가 없거나, 비공개 계정·삭제된 게시물이라 읽을 수 없으면 **INBOX에 그대로 남아요.** 직접 옮기거나 캡션을 고친 뒤 다음 실행을 기다리면 돼요.
- 이미 아카이브에 있는 게시물은 다시 넣지 않고 INBOX에서만 지워요.
- 규칙은 `src/lib/ig-route.ts`의 `HASHTAG_ROUTES`에서 바꿀 수 있어요.
- 인스타 계정은 **공개 계정**이어야 해요 (게시물의 공개 페이지에서 캡션을 읽어요).

## 처음 한 번

- **INBOX 페이지**는 자동화가 처음 돌 때 JUWON's ARCHIVES 안에 저절로 만들어요. 사이트에는 나타나지 않아요.
- **노션 연결 권한** — notion.so/my-integrations → 사이트용 연결 → 기능(Capabilities)에서 **콘텐츠 읽기 · 업데이트 · 삽입**이 모두 켜져 있어야 해요 (옮기기 = 삽입, INBOX에서 지우기 = 업데이트).

## (참고) 완전 자동: 프로페셔널 계정

프로페셔널(크리에이터) 계정으로 바꾸고 Meta 개발자 앱에서 받은 토큰을 GitHub Secret `IG_TOKEN`에 넣으면, INBOX 공유 없이 인스타에 올리기만 해도 같은 규칙으로 들어가요. 토큰은 60일마다 만료되며, `GH_SECRETS_TOKEN`(이 저장소의 Secrets 읽기/쓰기 권한 토큰)을 넣으면 매일 자동 갱신돼요.
